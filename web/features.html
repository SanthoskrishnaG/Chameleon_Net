How Heuristic DPI Operates on These Features:

1. Size Distribution:

Applications naturally exhibit characteristic MTU patterns. Audio codecs (G.711) transmit fixed 160-byte datagrams, while DNS queries rarely exceed 200 bytes.

2. Inter-Packet Timing (IPT):

Real-time protocols require strict isochronous timing (e.g., 20ms voice packets). In contrast, automated file downloads saturate link intervals.

3. Jitter & Bursts:

Jitter is the variance in delay. Video streaming pushes bursts of packets to fill client buffers, producing high burst counts followed by idle gaps.
